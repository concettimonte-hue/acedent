차량 로고 출처

차량 제조사를 구분하기 위한 보조 표시입니다. 각 로고와 상표의 권리는 해당 권리자에게 있으며, 공식 정비소·인증·제휴를 의미하지 않습니다.

원본 SVG·PNG 파일과 심볼의 도형·가로세로 비율은 유지합니다. 흰 받침 없이 표시하며, 단색 도형은 CSS로 밝은 회색으로 통일합니다. 은색 음영이 있는 벤츠·렉서스는 명암을 유지한 회색으로 조금 밝게 표시합니다. BMW·BYD·토요타·포르쉐·포드·혼다의 브랜드 색은 변경하지 않습니다.

밝은 회색 단색 표시: 현대, 폭스바겐, 기아, 제네시스, KGM, 르노코리아, 랜드로버, 링컨, 미니, 볼보, 아우디, 지프, 테슬라. 현대·폭스바겐의 파랑은 사이트 표시에서만 회색으로, 쉐보레는 노랑으로 바꿉니다. 원본 파일의 색상을 편집한 것이 아니라 CSS 표시 효과입니다. 가로형 심볼은 최대 32×20px 안에 맞추며, 포드·랜드로버도 글자가 구분되도록 이 크기로 표시합니다.

현대 H 심볼

Hyundai symbol — 작성자 TucsonMager79, 원출처 Hyundai.

Creative Commons Attribution-ShareAlike 4.0 International (CC BY-SA 4.0)을 선택하여 사용합니다. 제공하는 SVG에도 같은 라이선스를 적용합니다. 이 조건은 해당 자산에 대한 것으로, 사이트 전체 코드나 수리사례 사진에 적용되지 않습니다.

변경: XML 선언·외부 DTD·기존 비표시 주석 제거 및 출처 주석 추가. 색상·도형·viewBox는 변경하지 않았습니다. 이 라이선스는 별도의 상표 사용 허락을 의미하지 않습니다.

렉서스 L 엠블럼

Lexus division emblem — 작성자·원출처 Lexus. 로컬 SVG.

파일 페이지는 PD-logo / PD-USonly로 분류하며 원산국에서는 비자유 또는 비자유일 가능성이 있다는 주의를 함께 표시합니다. 이를 모든 지역의 사용 허가로 해석하지 않습니다. 공식 보도용 pressroom 파일을 사용한 것이 아닙니다.

변경: XML 선언·비표시 주석·메타데이터와 하단 LEXUS 워드마크 도형을 제거하고, 타원형 L 엠블럼에 맞춰 표시 영역(viewBox)을 조정했습니다. 남긴 엠블럼의 도형·색상·그라데이션·비율은 변경하지 않았습니다.

제네시스 날개 엠블럼

Genesis division emblem — 작성자 Blackspace, 원출처 Genesis, 2020. 로컬 SVG.

파일 페이지의 PD-logo / PD-USonly, 원산국 권리 주의 및 더 나은 출처 요청(better-source-request)을 그대로 기록합니다. 원권리자 재사용 허가를 확인했다는 뜻은 아닙니다.

변경: 비표시 메타데이터와 별도 하단 GENESIS 워드마크를 제거하고, 날개·중앙 엠블럼에 맞춰 표시 영역(viewBox)을 조정했습니다. 날개·중앙 문양과 그 안의 글자, 색상·비율은 변경하지 않았습니다.

테슬라 T 심볼

Tesla T symbol – white — 작성자 Tesla Inc., 원출처 Tesla.com. 로컬 SVG.

흰색 파일의 PD-textlogo 및 기타 제한 안내를 기록합니다. 관련 T 심볼 파일의 저작권 주장 주의도 남기며, 흰색 버전이라는 이유로 같은 형상의 권리 불확실성이 해소됐다고 보지 않습니다.

변경: XML 선언·비표시 주석·메타데이터 제거. 흰색·도형·viewBox 유지.

쉐보레·링컨 단독 심볼

쉐보레: Chevrolet simple logo의 하단 CHEVROLET 워드마크만 제외한 보타이 심볼을 사용합니다. 도형과 파일 색상은 유지하며, 화면에서만 CSS로 노랑 표시합니다.

링컨: Lincoln logo의 하단 LINCOLN 워드마크를 제외하고 별형 심볼에 맞춰 표시 영역을 조정했습니다. 원본 심볼의 도형·색상·비율은 유지하고, 화면에서만 CSS로 밝은 회색 표시합니다.

파일 페이지의 PD-textlogo 분류와 별도의 상표권 주의를 기록합니다. 교체 전 전체 로고와 출처 기록도 보존합니다.

포르쉐 방패 엠블럼

Porsche-seeklogo — 업로더·작성자 Kai xzzrs, 원출처 표기 Own work. CC BY 4.0 표기를 따른 표시용 PNG입니다.

변경: 비표시 XML 선언·주석 등을 제거한 뒤 원래 비율·색상·투명도를 유지하여 64×80px PNG로 렌더링했습니다. 화면에서는 20×20px 안에 맞춰 표시합니다.

이는 업로더가 표시한 라이선스이며 업로더의 권한이나 원브랜드의 사용 허가를 확인했다는 뜻은 아닙니다. 원브랜드의 저작권·상표권과 별개입니다.
