# 사이트 문구와 정보 수정 안내

사이트에 보이는 문구, 전화번호, 이미지 경로, 네이버 링크는 모두 `content/site.json`에서 수정할 수 있습니다. 파일을 열어 따옴표 안의 내용만 바꾸면 됩니다. 쉼표와 따옴표는 지우지 마세요.

## 항목별로 바뀌는 위치

- `meta`: 브라우저 탭 제목과 검색 결과에 표시될 사이트 설명
- `brand`: 상단과 하단의 에이스덴트 이름, 소개 문구, 로고 이미지
- `navigation`: 상단 메뉴 이름과 이동 위치
- `hero`: 첫 화면의 큰 제목, 소개 문구, 상담 버튼, 대표 전후 사진과 설명
- `stats`: 노란색 신뢰 정보 영역의 지역·월평균 차량·작업 기준
- `services`: `WHAT WE DO` 제목, 안내문, 외형복원·판금도색·광택·덴트 카드
- `cases`: 검은색 수리사례 영역의 제목, 차량명, 작업명, 사진, 블로그 링크
- `principles`: 작업 원칙 문구와 `WHY ACE DENT` 아래 세 가지 설명
- `naverLinks`: 네이버 블로그·스마트플레이스·톡톡·예약 카드의 문구와 링크
- `contact`: 전화번호, 문자·스마트플레이스 링크, 하단 상담 영역과 모바일 고정 버튼 문구

## 자주 수정하는 항목

### 전화번호 변경

`contact` 안에서 다음 세 값을 함께 바꿉니다.

- `phoneDisplay`: 화면에 보이는 번호 (예: `010-1234-5678`)
- `phoneHref`: 전화 버튼 주소 (예: `tel:01012345678`)
- `smsHref`: 문자 버튼 주소 (예: `sms:01012345678`)

### 수리사례 추가 또는 변경

`cases.items` 안의 각 묶음이 수리사례 카드 하나입니다.

- `vehicle`: 차량명
- `work`: 수리한 부위와 작업명
- `src`: `public` 폴더를 기준으로 한 이미지 경로
- `alt`: 사진을 보지 못하는 사용자를 위한 설명
- `href`: 해당 네이버 블로그 글 주소

새 카드를 추가할 때는 기존 `{ ... }` 묶음 하나를 복사해 내용을 바꾸고, 앞 카드 뒤에 쉼표를 넣어 주세요.

### 첫 화면 문구 줄바꿈

`hero.titleLines`와 `hero.descriptionLines`는 배열의 항목마다 한 줄씩 표시됩니다. 줄을 추가하고 싶으면 따옴표로 감싼 문장을 쉼표로 구분해 넣으세요.

### 이미지 교체

새 이미지를 `public/images` 폴더에 넣고 `hero.imageSrc` 또는 `cases.items`의 `src`를 `/images/파일명` 형식으로 바꿉니다.

## 수정할 때 주의할 점

- JSON 파일 안에서는 작은따옴표가 아니라 큰따옴표 `"`를 사용합니다.
- 마지막 항목 뒤에는 쉼표를 넣지 않습니다.
- 링크는 `https://`부터 전체 주소를 입력합니다.
- `content/types.ts`는 개발자가 데이터 구조를 확인하는 파일이므로 일반적인 문구 수정 때는 건드리지 않아도 됩니다.
